# Where you can’t watch: Unsupported device models YouTube apps

The current YouTube app won't work on certain device models, and older versions of the YouTube app won't work.

## Smart TVs, streaming devices, & game consoles

You can check if smart TVs, streaming devices, and game consoles are compatible with the YouTube app [here](https://support.google.com/youtube/answer/7582560).

## Update Android App Versions

If you get the following message, it means that the version you’re using is no longer supported. You'll need to update to access the YouTube app. To update to the latest version of the YouTube Android app, visit the Google Play Store.

![](https://lh3.googleusercontent.com/eakrMjjo1Ck2pUm-x9duqnb6bBcWgz_rDU5fHw0FFrM9WBeThb-OCA3gmyMyfIGU5Q=w500)

If you’d like to continue using YouTube without updating the app, visit [m.youtube.com](http://m.youtube.com/) in your mobile browser.

## Problems updating

If you can't update your app, your version of Android OS no longer supports the newer version of the YouTube app. To [get the latest version of the YouTube app](https://support.google.com/youtube/answer/7341336), update to the latest Android OS.

You can continue using the YouTube app without updating your OS, but eventually, older versions of the YouTube app won’t be supported. You can always visit [m.youtube.com](http://m.youtube.com/) in your mobile browser to watch YouTube.

## YouTube is no longer available on some devices

If you notice this message when you access YouTube on a smart TV, streaming device, or gaming console, the YouTube app will no longer work on your device.

**Message**: "YouTube is no longer available because this device doesn't meet the latest requirements."

We periodically update our security standards to keep user info safe. That means we turn off our services on devices that can no longer keep up with those standards. If your TV has a web browser, it may be possible to continue to use YouTube through youtube.com.

Sometimes, you can upgrade your device's firmware to restore access to the YouTube app. If you’re unsure how to upgrade your firmware, get in touch with your device manufacturer.
